# LOGOS p5.js Prototype v0.3 Visual Prototype

This version improves the visual presentation of the LOGOS browser prototype.

## Features

- Better HUD
- Spell sentence panel
- HP / Lingua / Flow display
- Enemy visual design
- Projectile VFX
- Particle effects
- Floating spell names
- Keyboard spell input
- GitHub Pages ready

## Controls

- 1 = FIRE
- 2 = WATER
- 3 = WIND
- 4 = EARTH
- 5 = LIGHT
- Q = SHOT
- W = BEAM
- E = WALL

## Example Spells

- FIRE
- FIRE + SHOT
- FIRE + WIND
- FIRE + FIRE + SHOT
- WATER + SHOT
- WIND + SHOT
- LIGHT + BEAM
- EARTH + WALL
