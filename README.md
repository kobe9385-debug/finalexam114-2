# LOGOS Godot Alpha 0.1

Godot 4 MVP starter project.

## Included

- Godot project structure
- Main scene
- BattlePage scene
- Player Word Core
- Lost Page enemy
- IGNIS SHOT projectile
- Sentence input prototype
- Basic assets
- Basic JSON data

## Controls

- Arrow keys: move
- 1: add IGNIS
- 2: add SHOT
- Space: cast sentence

Valid sentence:

`IGNIS SHOT`

## Open

1. Open Godot 4.x
2. Import this folder
3. Run `Main.tscn`

## Current goal

Alpha 0.1 only verifies the core battle loop:
player movement → sentence input → projectile → enemy damage.
